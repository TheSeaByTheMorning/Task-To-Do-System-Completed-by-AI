# 系统初始化说明

## 初始状态

本任务待办应用在首次下载和运行时，会以完全空白的状态启动，不包含任何预设的测试数据或示例内容。

## 数据结构

系统的默认数据文件（任务待办数据.txt）包含以下空结构：

```json
{
  "appTitle": "任务",
  "todos": [],
  "todoHistory": {},
  "unlockedAchievements": [],
  "lastUpdated": ""
}
```

- **appTitle**: 默认标题为"任务"，用户可以通过双击标题进行自定义
- **todos**: 待办事项列表，初始为空数组
- **todoHistory**: 待办完成历史记录，初始为空对象
- **unlockedAchievements**: 已解锁成就列表，初始为空数组
- **lastUpdated**: 最后更新时间，初始为空

## 首次使用

当您第一次打开应用时，您将看到：

1. 顶部显示默认标题"任务待办"
2. 中间显示"暂无待办，请添加待办事项"的提示
3. 进度统计显示为0%完成率
4. 所有成就都处于锁定状态
5. 鼓励小贴士区域会显示随机加载的励志语句

## 开始使用

要开始使用应用，您可以：

1. 在输入框中输入您的第一个待办事项，然后点击"+"按钮或按Enter键添加
2. 点击"加载数据"按钮导入已有的待办数据文件
3. 双击"任务"文本自定义应用标题
4. 点击"保存数据"按钮创建您的数据备份

## 数据安全

- 所有数据默认保存在浏览器的localStorage中
- 建议定期通过"保存数据"按钮导出数据文件进行备份
- 清除浏览器数据可能会导致本地存储的数据丢失

## 注意事项

- 首次使用时，应用需要从网络API获取鼓励语句，这可能需要几秒钟时间
- 如果您希望从示例数据开始，可以创建一个包含示例待办的JSON文件，然后通过"加载数据"功能导入
- 系统不会自动创建任何测试数据，确保您的使用体验完全干净
