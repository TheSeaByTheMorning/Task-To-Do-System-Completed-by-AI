任务待办系统 - 纯AI完成 / Task To-Do System - Completed purely by AI

# 任务待办应用

一个功能完善的任务待办应用，支持任务管理、进度追踪、数据可视化和成就系统，帮助用户高效管理日常任务，提升工作效率和成就感。

![任务待办应用截图](https://example.com/screenshot.png)

## 功能特点

### 1. 待办管理

- 添加、删除、标记完成状态
- 点击待办项整行即可完成/取消完成
- 批量导入多个待办事项
- 自动检测重复项，避免重复添加

### 2. 进度追踪

- 实时显示完成率和统计数据
- 进度条颜色随完成率变化（0%、<25%、<50%、<75%、≥75%）
- 统计总待办、已完成、未完成数量
- 完成率达到25%、50%、75%、100%时进度条颜色变化

### 3. 数据可视化

- 使用Chart.js创建待办完成情况饼图
- 图表会根据待办完成情况实时更新
- 100%完成时图表样式优化，移除边框避免缝隙
- 直观展示完成与未完成待办的比例

### 4. 成就系统

- **起步者**：完成25%的待办事项
- **执行者**：完成50%的待办事项
- **高效者**：完成75%的待办事项
- **完成大师**：完成全部待办事项
- 成就会根据完成率实时更新，不再满足条件时会自动锁定
- 成就解锁时有通知提示，卡片边框变为黄色
- 每个成就卡片显示进度条，直观展示距离解锁成就的进度

### 5. 鼓励小贴士

- 从多个网络API获取随机鼓励语句
- 支持中国古代名言、国内外名人名言、人民日报金句、现代网络热门句子、中国谚语
- 使用本地存储保存已显示过的句子ID，确保不会重复显示相同内容
- 添加了加载动画，提升用户体验

### 6. 标题自定义

- 双击左上角的"任务"文本，可自定义应用标题
- 自定义标题会保存到本地存储
- 页面标题也会同步更新
- 添加了彩蛋效果，标题更改时会有颜色变化动画

### 7. 数据导入导出

- 支持从文件导入待办数据
- 支持将待办数据导出到文件
- 导入时自动检测重复项，避免重复添加
- 支持批量导入多个待办事项

### 8. 新建数据功能

- 创建新的空白数据环境
- 自动重置系统标题为默认值"任务"
- 清空所有待办事项和成就
- 确保新数据环境完全干净

## 使用指南

### 基本操作

1. **添加待办**：在输入框中输入待办事项，点击"+"按钮或按Enter键添加
2. **标记完成**：点击待办左侧的圆形图标或点击整行
3. **删除待办**：点击待办右侧的垃圾桶图标
4. **批量导入**：点击"展开"按钮，粘贴待办列表（每行一个），点击"导入"

### 数据管理

1. **保存数据**：点击"保存数据"按钮，将当前所有数据保存为.txt文件
2. **加载数据**：点击"加载数据"按钮，选择之前保存的.txt文件
3. **新建数据**：点击"新建数据"按钮，创建新的空白数据（会清除当前数据）

### 标题自定义

- 双击左上角的"任务"文本，可自定义应用标题
- 标题格式为"xxx待办"，其中"xxx"可自定义，"待办"部分固定不变

### 成就系统

- **起步者**：完成25%的待办事项
- **执行者**：完成50%的待办事项
- **高效者**：完成75%的待办事项
- **完成大师**：完成全部待办事项

## 问题解决

### 数据加载问题

如果遇到数据加载问题，可以尝试以下步骤：

1. **检查文件格式**：确保加载的是正确的.txt文件，文件内容应为JSON格式
2. **查看调试日志**：
   - 在Chrome中按F12打开开发者工具
   - 切换到"Console"标签
   - 点击"加载数据"按钮，查看控制台输出的日志信息
   - 根据日志信息判断问题所在

### 常见错误及解决方法

1. **"文件内容为空"错误**：
   - 检查文件是否为空
   - 确保文件路径正确

2. **"JSON解析错误"**：
   - 文件内容不是有效的有效的JSON格式
   - 可以先使用"保存数据"功能导出一个正确格式的文件作为参考

3. **"待办数据格式不正确"**：
   - 文件中缺少todos字段
   - todos字段不是数组格式

## 数据格式说明

正确的数据文件应包含以下字段：

```json
{
  "appTitle": "应用标题",
  "todos": [
    {
      "id": 123456789,
      "name": "待办事项名称",
      "completed": false
    }
  ],
  "todoHistory": {
    "7-21": 2,
    "7-22": 1
  },
  "unlockedAchievements": ["beginner"],
  "lastUpdated": "2023-07-21T12:00:00.000Z"
}
```

- **appTitle**：应用的自定义标题
- **todos**：待办事项列表数组
- **todoHistory**：待办完成历史记录对象
- **unlockedAchievements**：已解锁成就数组
- **lastUpdated**：最后更新时间戳

## 最近更新

### 成就系统实时更新功能

- **成就动态管理**：成就系统现在会根据待办完成率实时更新
- **解锁与锁定**：完成率达到相应阈值时自动解锁成就，低于阈值时自动锁定
- **进度条显示**：每个成就卡片添加了进度条，直观展示距离解锁成就的进度
- **无待办处理**：当没有待办事项时，自动重置所有成就
- **实时状态更新**：成就状态变化立即反映在UI上，无需刷新页面

### 标题重置功能优化

- **新建数据时标题重置**：创建新数据时，系统标题会自动恢复为默认值"任务"
- **页面标题同步更新**：页面标题也会同步重置为"任务待办"
- **确保全新环境**：新数据环境完全干净，包括标题设置和所有数据

### 鼓励语句功能优化

- **增加API源多样性**：集成了多个免费API源（一言API、语录API、ZenQuotes、Quotable、Xemowo），确保内容丰富多样
- **解决重复内容问题**：使用本地存储保存已显示过的句子ID，确保不会重复显示相同内容
- **改进加载提示**：超过1秒未获取到内容时显示"正在获取内容..."的动态提示
- **持久化存储**：已显示过的句子ID会保存在本地存储中，即使关闭浏览器后重新打开也不会重复显示相同内容
- **页面加载优化**：页面加载时也会从网络API获取内容，而不是使用固定内容

### 其他用户体验改进

- **待办交互优化**：点击待办项整行即可完成/取消完成，提升操作便捷性
- **进度条颜色优化**：根据完成率显示不同颜色，更直观地反映进度状态
- **图表显示优化**：100%完成时移除边框，避免出现视觉缝隙
- **批量导入优化**：支持按行分割待办事项，导入时自动检测重复项
